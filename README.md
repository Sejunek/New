# SELF / SENSE — 나를 보는 나의 기준

서비스: https://sejunek.github.io/New/
저장소: https://github.com/Sejunek/New

## 현재 버전
이름 입력 → 최근 한 달의 경험을 돌아보는 10문항 → 자기 가치 수준(X)과 자기평가 안정성(Y) → 답변 수정, 메일 요약 작성, 결과 파일 저장.

- 이름은 필수(공백 제외 1–24자)이며 URL에 넣거나 서버로 보내지 않습니다.
- 문항마다 1–10을 직접 선택합니다. 기본 선택값은 없고 ‘경험 없음’을 따로 고를 수 있습니다.
- 이전 문항으로 돌아가거나 결과에서 특정 답변을 수정할 수 있습니다.
- PC와 모바일에서 사용할 수 있으며 키보드로도 응답할 수 있습니다.
- 디자인은 짙은 배경과 라임·보라 포인트, 진행 표시, 2축 좌표와 축별 점수로 구성합니다.

## 점수
홀수 문항 5개: 자기 가치 수준. 평균(응답−1) ÷ 9 × 100.
짝수 문항 5개: 자기평가 안정성. 평균(10−응답) ÷ 9 × 100.
각 축을 정수로 반올림합니다. 경험 없음은 분모에서 제외합니다. 축별 유효 응답이 3개 미만이면 해당 점수는 표시하지 않으며, 두 축 모두 충분할 때만 좌표를 표시합니다.

0–33 / 34–66 / 67–100은 서비스의 임의 표시 구간이며 백분위·임상 기준·검증된 규준이 아닙니다. 중앙 선택에 객관성 가점을 주지 않습니다. 두 축을 하나의 메타인지 점수로 합산하지 않습니다.

이 문항은 검증 전 자체 제작 문항입니다. 단회 자기보고로 기억하는 자기평가 수준과 변동을 살펴보며, 실제 메타인지 능력·과대과소평가·질투·갈등 위험을 판정하지 않습니다. 기존 척도의 문항이나 타당도를 그대로 사용하지 않습니다.

참고한 연구:
- 엄홍식·박기환(2026), 한국판 메타인지 자기평가 척도(K-MSAS) 타당화.
- 정복성·함상우(2018), 메타인지, 자기효능감 및 자기존중감의 관계에 관한 연구.
- 이금성(2024), LLM 기반 메타인지 진단평가 시스템 설계 및 구현.
- Altmann & Roth(2018), The Self-esteem Stability Scale. https://doi.org/10.3389/fpsyg.2018.00091
LLM 분석 기능은 포함하지 않습니다.

## 개인정보와 메일
이름·응답·결과·이메일은 현재 탭의 메모리에서만 처리합니다. DB, 쿠키, 브라우저 저장소, 분석 도구, 외부 폰트, 결과 서버 전송이 없습니다. 새로고침·탭 닫기·새 검사 시작 시 초기화됩니다. 호스팅의 일반 접속 로그는 별개입니다.

메일은 mailto로 기기의 메일 앱에 요약만 채웁니다. 사용자가 내용을 확인하고 직접 보내야 합니다. 메일 앱에 따라 동작이나 본문 길이가 제한될 수 있어 전체 결과 텍스트 다운로드를 함께 제공합니다. 발송한 메일과 내려받은 파일은 사용자가 선택한 서비스·기기에 남을 수 있습니다. 이메일 자동 발송은 구현하지 않았습니다.

## 실행 및 수정
설치나 빌드 없이 최상위 index.html을 열거나 정적 HTTP 서버에서 실행하세요.
GitHub Pages는 master 브랜치의 /(root)를 게시합니다. 최상위 파일 변경을 커밋하면 자동 배포됩니다.

- questions.js: 승인된 문항과 양끝 문구
- score.js: 축별 환산·응답 부족 처리
- app.js: 이름·설문·리포트·내보내기
- style.css: 반응형 UI
- index.html: 페이지 및 측정·개인정보 안내
- tests/score.test.js: 점수 계산 검증. 실행: node tests/score.test.js
